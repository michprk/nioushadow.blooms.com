# Photos du site

Photos reprises du site actuel de Nioushadow Blooms (section « Special Offers »).
Elles ont été découpées dans une capture d’écran puis agrandies : pour plus de netteté,
remplace-les par les fichiers originaux **en gardant exactement les mêmes noms**.

| Fichier               | Photo                                   | Où elle apparaît                                                |
|-----------------------|-----------------------------------------|-----------------------------------------------------------------|
| `bouquet-mariee.jpg`  | Bouquet de mariée, roses blanches       | Accueil (cadre sur les livres), Créations › Mariages, Carnet    |
| `roses.jpg`           | Roses roses et rouges                   | Accueil (cadre à côté de « Blooms »), Abonnement, Carnet        |
| `bouquet-boite.jpg`   | Bouquet en boîte tenu à deux mains      | L’atelier, Créations › Abonnements, Carnet                      |
| `bouquet-saison.jpg`  | Bouquet de saison dans un vase en verre | Créations › Bouquets, Abonnement (grand cadre), Carnet          |
| `bouquet-seche.jpg`   | Bouquet de fleurs séchées               | Créations › Événements, Carnet                                  |

Pour ajouter une nouvelle photo : dépose-la ici, puis dans `index.html` change le `src="…"`
de l’emplacement voulu (et son texte `alt="…"`, qui décrit la photo pour les personnes
aveugles et pour Google). La ligne « Plantes rares » attend encore une photo de plante :
un commentaire dans `index.html` indique où l’ajouter.

Conseil : garde chaque fichier sous 300 Ko (JPEG qualité ≈ 80, 1600 px de large maximum).
