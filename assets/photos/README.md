chaque photo ajoutée remplace simplement l’illustration correspondante.

Conseils :

- Les photos sont recadrées automatiquement (`object-fit: cover`) : le format conseillé évite
  seulement de perdre les bords.
- Garde chaque fichier **sous 300 Ko** (JPEG qualité ≈ 80, 1600 px de large maximum) pour que
  le site reste rapide.
- Les légendes du carnet (N°01, N°02…) et les textes alternatifs se modifient dans `index.html`.
